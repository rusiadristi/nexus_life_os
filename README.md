# 🌿 Nexus Life OS — Professional Productivity & Portfolio App

Aplikasi mobile berbasis **Flutter** dengan estetika **Modern Executive Slate**: warna yang lembut, nyaman di mata, tidak mencolok (*clean, non-gimmicky*), dan didesain secara profesional seperti standar aplikasi produktivitas kelas dunia (Linear, Notion, Apple, Stripe).

---

## 🎨 Perubahan Desain & Karakter Visual

- **Palet Warna Lembut**: Menggunakan *Soft Slate Navy* (`#0E131F`), *Polished Slate Surface* (`#161E2E`), dan aksen *Soft Indigo* (`#6366F1`), *Muted Sky Blue* (`#38BDF8`), *Soft Lavender* (`#818CF8`), serta *Muted Emerald* (`#10B981`).
- **Bebas Kesan Sci-Fi Berlebih**: Menghilangkan efek neon/glow yang menyilaukan dan menggantinya dengan bayangan lembut (*subtle elevation*), garis batas tipis (*hairline border*), dan sudut membulat yang proporsional.
- **Tipografi Bersih & Elegan**: Menggunakan font **Plus Jakarta Sans** di seluruh aplikasi untuk kenyamanan membaca optimal dan tampilan eksekutif.

---

## 📱 Fitur Utama Aplikasi

1. **Dashboard & Ringkasan Harian**:
   - Skor Produktivitas Harian (0 - 100) dan metrik fokus kerja & energi tubuh.
   - Grafik garis lembut untuk tren konsistensi kerja mingguan.
   - Pintasan aksi cepat untuk memulai fokus, menambah tugas, dan memeriksa portofolio.

2. **Asisten Produktivitas**:
   - Dialog interaktif untuk menyusun rencana kerja, strategi karir, dan alur kerja harian.
   - Template topik siap pakai (Rencana Belajar, Manajemen Waktu, Strategi Finansial, dsb).

3. **Daftar Tugas & Prioritas**:
   - Kategorisasi terstruktur (*Deep Work, Finansial, Teknologi, Pola Hidup*) dengan indikator tingkat urgensi.
   - Poin pencapaian setiap kali tugas diselesaikan.
   - Form penambahan tugas baru yang bersih dan fungsi hapus tugas dengan gestur geser (*swipe-to-delete*).

4. **Sesi Fokus & Deep Work**:
   - Timer melingkar dengan pilihan siklus Pomodoro adaptif (25 menit, 50 menit, istirahat 10 menit, dan sesi puncak 90 menit).
   - Opsi suara latar relaksasi (Gelombang Alpha, Fokus Binaural, Suara Hujan Lembut, White Noise, Hening).

5. **Portofolio & Aset Finansial**:
   - Valuasi total dalam mata uang USD dan estimasi Rupiah Indonesia (IDR).
   - Grafik kinerja portofolio dan pencatatan aset investasi (Saham teknologi, ETF energi hijau, aset digital).
   - Tombol sinkronisasi pembaruan harga pasar secara *live*.

6. **Pengaturan Sistem**:
   - Personalisasi nama profil dan preferensi keamanan biometrik (Face ID / Sidik Jari).
   - Respon getaran taktil (*Haptic Feedback*) dan info diagnostik aplikasi.

## 🚀 Cara Menjalankan Aplikasi

Jalankan perintah berikut di terminal:

```bash
# Menjalankan di Chrome / Web browser:
flutter run -d chrome

# Menjalankan di Android Smartphone / Emulator:
flutter run
```
